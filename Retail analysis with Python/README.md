# Retail Data Analysis

## Project Overview

This project analyzes a retail dataset to uncover insights into customer purchasing behavior. The dataset contains transactional data, including product details, quantities sold, prices, and customer identifiers. The main objective is to clean, pr ocess, and visualize the data to extract meaningful insights.

## Key Steps

1. **Data Loading**: The dataset, provided as an Excel file, is loaded into a Pandas DataFrame.
2. **Data Cleaning**:
   - Handling missing values by removing rows with null descriptions.
   - Identifying and filtering out negative quantities and zero or negative prices.
   - Dropping unnecessary columns, such as invoice numbers and stock codes.
3. **Exploratory Data Analysis (EDA)**:
   - Statistical summaries of numerical variables.
   - Detection of outliers and potential anomalies in purchasing behavior.
4. **Data Visualization**:
   - Various plots are generated to illustrate trends in sales and customer activity.

## Technologies Used

- Python
- Pandas
- Seaborn
- Matplotlib
- NumPy

## Purpose

This analysis helps retailers understand sales trends, detect anomalies, and improve business strategies based on customer behavior.
